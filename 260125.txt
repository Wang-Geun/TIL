오늘의 작업
1. SSAFY python 4장 level 5 문제 코드 작성
-> 여러 개의 조건을 한 변수 안에 담아 각각 조건을 만족하면 FALSE를 반환하며 
   FALSE를 반환한 조건을 리스트로 담아 출력을 해야 하는 문제였음.
    1) 처음에는 모든 조건들을 or 로 붙여서 하나라도 조건을 만족하면 FALSE를 출력하는 방식으로 
       코드를 작성함
    2) 하지만 모든 조건들을 or로 붙여서 하나의 FALSE를 출력할 경우 2개 이상의 조건이 만족되어
       FALSE를 출력하면 2개 이상의 조건들이 각각 어떤 조건들인지 모를 수 있다는 경우를 생각함
    3) 그래서 각각의 조건들에 if 문을 붙여 개별적으로 FALSE를 출력하도록 했음.
    4) 하지만 결국 같은 FALSE를 출력했고 다시 어떤 조건이 FALSE를 출력했는지 알아내 그 값을
       출력해야 하는데 결과적으로 어떻게 도출해야 하는지 모르겠음.
-> 결론: 2가지 경우의 수를 가지고 코드 작성을 계속 했지만 아직 기본기가 부족하여 논리문법
         구조를 정확히 파악하지 못하여 내가 구상하던 방식을 실현하기 부족했다고 느낌.
-> 개선점: 논리 구조에 대해서 좀 더 많이 구현하여 경험을 늘릴 필요가 있다고 생각함.
