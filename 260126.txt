오늘의 작업
1. 강의 정리
- 메서드 호출 방법 (데이터 타입 객체.메서드())
- 모듈 함수() != 객체 함수()
- .sort()와 sorted의 차이점: 리스트의 method(반환값 X) vs 내장 함수(반환 O)
- 얕은 복사: a와 b의 주소는 다르지만 내부 객체의 주소가 같아 내부 객체를 변경하면 따라서 변경됨
  깊은 복사 → copy 모듈에서 제공하는 deepcopy() 함수 사용
- 메서드 체이닝에서 각 메서드가 반환값을 가지고 있는지 유무에 따라 체이닝이 
  가능한 경우가 있고 없는 경우가 있다.

2. 과제 풀이
-> 코드 작성 과정에서 .pop()에 대한 사용법이 아직 익숙하지 않았고, 반복문에 대해서 무조건
for문을 사용하여 작성했지만 오늘 강사님이 사용하신 while문이 나의 for문보다 훨씬 짧고
쉽게 코드를 작성할 수 있다는 것을 보고 while문이 왜 사용되는지 깨닫게 됨.

3. SWEA 문제 풀이
1) 거꾸로 출력
T = int(input())

for test_case in range(0, T + 1):
    print(T, end=' ')
    T -= 1
# input = 8, output = 8 7 6 5 4 3 2 1 0

2) 더블더블
T = int(input())

for test_case in range(0, T + 1):
    print(2**(test_case), end=' ')

# input = 8, output = 1 2 4 8 16 32 64 128 256
-> 오늘 과제를 진행하면서 배운 end=''를 잘 활용한 코드였다.

3) 가위바위보

A, B = map(int, (input().split()))
    
if A == 3:
    if B == 1:
        print('B')
    else:
        print('A')
elif A == 2:
    if B == 1:
        print('A')
    else:
        print('B')
elif A == 1:
    if B == 2:
        print('B')
    else:
        print('A')

# input = 3 2, output = A
-> 좀 더 간결하게 만들 수 있을 것 같지만 집중력 부족으로 노가다 느낌의 코드를 작성했다고 생각함.
   추후 남는 시간에 좀 더 간결하게 코드를 작성해보도록 하겠음.
