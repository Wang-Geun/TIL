1. 객체 지향 프로그래밍
    1) class
    2) instance

객체는 속성(변수)와 동작(메서드)를 가진다.

내가 적어보는 class의 기본 형태

def class:
    def __init__(self):

    @classmethod
    def ~ (self):

    @staticmethod
    def ~ (self):

강의를 들을 때에는 잘 이해가 가지 않았지만 실습과 과제 풀이를 하면서 어느정도 기본적인 감은
잡았다고 생각이 든다.

2. 과목 평가, 월말 평가
- 과목 평가: 문제에 대한 답을 정확하게 알지 못하고 애매하게 알고 있어서 문제가 그 점을 정확하게 노리고
            출제된 것 같다. 
- 월말 평가: 문제 자체를 푸는데는 무리가 없지만 10번은 시간 상 풀지 못했다. 코드를 작성하는 것은
            계속 오류를 확인하고 수정하는 과정으로 진행해서 큰 무리 없이 코드 문제들을 풀어나감.

개선점: 아마 과목 평가 과락을 받은 것 같은데 기본적인 문법에 대한 개념이 아직 많이 부족하다는 것의
        반증이라고 생각한다. 당연히 기본 문법 코드 문제는 다 풀리기 때문에 문제가 없다고 생각했지만
        생각보다 내게 보이지 않던 구멍이 꽤나 컸다. 추후 다음 과목 평가를 공부할 때에도 개념 공부를
        좀 더 착실히 해야할 필요성이 커짐.
